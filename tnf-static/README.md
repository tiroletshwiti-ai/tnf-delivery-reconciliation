# TNF Delivery Reconciliation (static MVC)
Open index.html, or drag this folder onto Netlify. Data (47 September 2026 deliveries) is seeded into the browser's localStorage.
- models/   calc.js (rules), deliveries.js (data access)
- views/    views.js (HTML templates)
- controllers/ controllers.js (page logic)   - app.js = router
