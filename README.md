# tnf-delivery-reconciliation
Tswana Nexus Fuel Delivery Reconciliation is a web app that checks fuel deliveries against what each site actually received. It replaces the monthly “Sites Supplier Recon - Losses and Gains” Excel workbook.  What it does  Records each fuel delivery: site, supplier, transporter, truck,driver,deliverynote product,and the litres loaded by the supplier
